# Full Windowed Youtube

Open source Firefox extension that adds a button to YouTube's control bar to fill the browser window with the player.

It does one thing: it adds a button with a clear, user-friendly window icon just before YouTube's fullscreen control. Click it and the player fills the whole browser window. Click it again or press Escape and the page comes back.

![The full-window button sits in YouTube's control bar, left of the fullscreen icon](img/screenshot.png)

The icon is drawn to YouTube's own icon standard: a single centred glyph, optically balanced inside its hit area, with the same stroke weight and corner radius as the controls around it. It reads at a glance like the rest of the bar and needs no legend.

- No hidden tracking, no analytics, no network requests
- No account, no sign-in, nothing stored
- No ads, no ups, no paid version
